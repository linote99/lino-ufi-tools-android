# scrcpy 5.0.1 protocol notes (source: https://github.com/Genymobile/scrcpy tag v5.0.1, server/src/main/java/com/genymobile/scrcpy/*; doc/develop.md)
- Server binary: https://github.com/Genymobile/scrcpy/releases/download/v5.0.1/scrcpy-server-v5.0.1 (733930 bytes), SHA-256 764eb6f79811d5211fe9df341120882ba9994c7a61b897d7bf3fb662e53bc536 (matches SHA256SUMS.txt). Apache-2.0.
- Run: CLASSPATH=/data/local/tmp/x.jar app_process / com.genymobile.scrcpy.Server 5.0.1 key=value...  (version must match exactly)
- Options: scid (hex, 31-bit), log_level, video, audio, video_codec, max_size, video_bit_rate, max_fps, tunnel_forward, control, stay_awake, power_off_on_close, clipboard_autosync, cleanup, power_on, send_device_meta, send_frame_meta, send_dummy_byte, send_stream_meta, raw_stream ...
- Socket name: "scrcpy_%08x" (scid). tunnel_forward=true: device listens (LocalServerSocket), accepts video, (audio), control in order. Dummy byte 0 on the first socket. Device meta = 64-byte name on first socket if send_device_meta.
- Video socket: u32 codec id (h264 0x68323634; 0 = disabled, 1 = error). Then session packet (12 bytes: u32 flags with MSB=1 [bit0 client-resize], u32 width, u32 height) per capture session (rotation), then media packets: 12-byte header u64 (bit63=0, bit62 config, bit61 key frame, PTS) + u32 size, then payload. Big-endian.
- Control msgs (big-endian): type 0 INJECT_KEYCODE: action u8, keycode i32, repeat i32, metastate i32 (14 bytes). type 2 INJECT_TOUCH: action u8, pointerId i64, x i32, y i32, screenW u16, screenH u16, pressure u16 fixed point, actionButton i32, buttons i32 (32 bytes). type 4 BACK_OR_SCREEN_ON: action u8. type 10 SET_DISPLAY_POWER bool. type 17 RESET_VIDEO.
